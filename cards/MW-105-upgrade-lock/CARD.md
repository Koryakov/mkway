## 1. Goal

«a follow-up card does the lock-gate change with its own red proof, reusing MW-103's helpers.absolute and outside-path records once merged» — order of the operator, ruling R257h, 2026-11-14. Gap H7 of MW-104: the upgrade folder holds the green record and the owner's grant, and the lock gate maps every path through `ctx.norm`, which gives None outside the root, so that folder is unguarded. One built-in never-open target `upgrade` guards the whole folder (the default resolution and the override folder) for edit tools and shell writes (R260 a to f, R260a, R260b, R260c).
