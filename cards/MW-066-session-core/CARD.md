How to use: this card follows `cards/_TEMPLATE/CARD.md`; written by hand, as `card new` cannot run in the engine
repository. `VERSION` is not changed here. The family is the session gates: the subtask gate, the lead gate (edit, shell,
remind), the message gate (send, remind, stop), the records step of the `post` group and the agent records. The commit gate
(MW-052) and the other families have their own cards; `engine/core.py` is not touched.

## 1. Goal

The owner: «it looks like wrong tests concept». The ruling: a test proves a behaviour at the layer where its fault can
live; decisions are a pure core with table tests; reading facts is a shell tested on real files (20 s per test); the
contract with Claude Code is e2e (one deny per reason). This card moves the decisions of the session gates into
`engine/core_session.py` (small Facts and Verdict records, no I/O import); each gate module becomes a thin shell that reads
the register, the records, the leads file, the inbox and the hook input, calls the decision, and writes what the verdict
says. Behaviour does not change: the old tests of the family passed unchanged against the shells before they were moved.
