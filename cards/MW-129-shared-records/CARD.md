## 1. Goal

«Every per-card record has one home per task, the shared folder, so a record written in any checkout (main or an mkcl worktree) is read by every gate in every checkout and survives the worktree's removal. Gates read card records ONLY from the shared folder, never from another checkout's state.» — order of 2026-11-16, ruled by R307.

A task that uses worktrees sets `state.shared_dir`; without it card records, like the inbox and the locks, are per checkout.
