## 1. Goal

«ONE call lists the WHOLE history of HEAD (commit, tree id, committer time). No count, no date option, no margin, no --since-as-filter.» — chief, R313, 2026-11-16. `verdict add` finds a card's red-proof row however many unrelated commits followed the red commit; a row whose tree is in no commit of HEAD still counts for nothing.

Texts of the one reason id `verdict-no-red-proof` (the way out is the same red commit, except (iv)): (i) `the card has no red-proof row, so its tests were never proved red; commit the card's red tests (the commit gate records the row), then call again`; (ii) `the card's red-proof rows name trees that no commit of HEAD has, so the red commit was never made on this branch; commit the card's red tests (the commit gate records the row), then call again`; (iii) `the search for the commit of the card's older red-proof row (no git tree) ran out of time (limit 60 s) after N commits checked; commit the card's red tests (the commit gate records the row), then call again`; (iv) `the git history of HEAD could not be read, so the card's red-proof rows could not be checked; repeat the call`.
