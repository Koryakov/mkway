## 1. Goal

«the commit gate finds a card's OWN red record however many unrelated commits followed the red commit. No commit count. Never weaker: a row whose tree is in no commit of HEAD counts for nothing.» — order of 2026-11-16 (retro-oper10, R314 to R323).

The commit gate reads the card's red record through the search MW-130 put in `gate_commit_tests.py` (`find_red_rows`): ONE `git log` listing of the whole history of HEAD; a row with a `git_tree` is found when that id is listed (no digest work); a row with no `git_tree` (a legacy row) is found by the digest, nearest commit first, under one wall-time limit (`OWN_RECORD_SEARCH_SECONDS`, 3 s, R323). The record is the union of the FOUND rows. `_others_red` and `_head_red` keep `TREE_LIMIT`.

Texts of the reason id `red-not-recorded` (one text per cause, the wording of R324; `{card}` the card id, `{n}` the number of distinct git trees digested): (i) `{card} has no red record: no tests-only commit of the card was recorded as red; commit the failing tests first, alone (the gate runs them and records the red), then commit the code; if they were committed in another checkout, commit the code there`; (ii) `{card} has red record rows, but none of them belongs to a commit in the history of HEAD: the red commit was not made, or it sits on a branch that is not merged here; commit the code where the red tests were committed, or, if they were never committed, commit a failing test of the card first, alone (the gate runs it and records the red), then commit the code`; (iii) `the search for the older red record rows of {card} (written with no git tree) ran out of time (limit 3 s) after {n} git trees checked, and no row was found; commit a failing test of the card, alone (the gate runs it and records the red; a further tests-only red commit renews the record), then commit the code`; (iv) `the git history of HEAD could not be read, so the red record of {card} could not be checked; repeat the call`. The new warn id `red-record-partial` (R322, R324): `the red record of {card} was read without {k} older row(s) written with no git tree (times {t1}, {t2}) because the search for them ran out of time (limit 3 s); the check goes on with the rows that were found; this line needs no action`.
