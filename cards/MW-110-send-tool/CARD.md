## 1. Goal

«we should have straight, simple as its possible mkway process - it should help work on tasks - not be as evil dog - it should be strong helper!» — owner, 2026-11-16 (R263). Help given to the task: a session sends a message with one engine call and needs no one-use permit; free text over SendMessage passes; the inbox file stays the record of orders and results; the ping stays a Claude action and its Stop gate stays. Session identity comes from the launcher's environment variable, checked by every shell hook call against the hook's own session id. Concept: line 1 (the tool is the «everything else») and line 3 (the tool is the way out); exit `tool`; record R1. Scope: this card only; `message-not-in-inbox` is removed (exit `remove`, card 5); the ping gate's table stays as it is.
