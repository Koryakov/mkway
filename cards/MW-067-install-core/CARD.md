## 1. Goal

«only fix that tests! go! faster as possible!» — owner, 2026-11-12.
Install is not a gate: its decisions (which files are copied, what is written into the lock, the settings file, the
ignore and attributes files, the commit line, the refusals, the lines of `check`) move into `engine/core_install.py`,
pure: small facts and verdict records, no disk, git, process or clock. `engine/install.py` stays the shell: it reads
the facts, asks the core, copies and writes. Behaviour does not change. The tests follow the layers: table tests of
the core (`tests/core/test_install_decide.py`), real folders and real git in one shared session install
(`tests/shell/test_install_facts.py`, each test under 20 s), the real hook cases stay where they are. Not established:
whether the hook-driven cases of the live install gate (`test_mw030_live_install.py`) should join the session install;
they stay as they are.
