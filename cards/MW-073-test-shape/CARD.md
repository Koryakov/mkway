## 1. Goal

Plan gate G7 with gap 4 of ruling R177 (gate key `tests.shape`): a commit that adds or changes a test function is
refused `test-shape` when the function breaks one of the shape rules S1 to S7. Only functions added or changed in the
commit are judged (an AST diff by function between HEAD and the committed tree), never a whole old file. The profile
key `tests.shape.mode` is `trip` (default, refuses) or `watch` (writes its record row and the reason line, allows).
A one-off report lists every existing test function that breaks S1 to S7, per rule and per file.

Rules: S1 no `for`, `while` or `if` in a test body. S2 at least one `assert` or `pytest.raises`. S3 no `assert True`,
`assert False`, no `assert a and b`. S4 a one-line docstring that starts `Catches:` or `Checks:`. S5 no import of
another test module (`test_*` or `tests.*`; a helper that starts with `_` is allowed), and no literal that names
another test file. S6 no `time.sleep`, `socket`, `requests`, `urllib`, `http`, and no absolute path literal. S7 in a
test under `tests/core` the expected side of `==` is a literal or a parametrize argument, never a call.
