## 1. Goal

«Commit checks (right files only, own changes only, no junk, no data files)» — owner, 2026-11-10.
The engine gets one generic commit gate in the shell group: a session's `git commit` is refused when it holds a file
outside the open card's Paths, a file this session never touched, a junk file, a git-ignored file that was force-added,
a data file or an oversized file, or when its message does not name the open card. The owner's terminal is not gated.

### Families of the source commit check (rule 0)

The source module has no letters; A-L are assigned here, in the order of the module's gates (21 gate functions grouped
into 12 families). No code is copied. The source has no junk, ignored-file, data-file or size check at all: rules 3 and
4 of the order are new here, in no family.

| Family | What the source refuses | Fate |
|---|---|---|
| A | a commit that changes a pipeline file without naming an open work item in its message | built here: rule 5 (the message names the open card's id); the pipeline-file notion stays with the task, the engine checks every commit |
| B | `--no-verify`, `-n` or a replaced hooks path (a commit that skips git hooks) | dropped: not in the order's goal line, and the engine installs no git hook; a card of its own can add it |
