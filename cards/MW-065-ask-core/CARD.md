## 1. Goal

«only fix that tests! go! faster as possible!» — owner, 2026-11-12, through the architect's migration task.
The decisions of the ask family (the owner-ask edit gate and stop gate, the search gate, the outbox check write gate) move
into `engine/core_ask.py`: small Facts records in, a Decision out, no disk, no process, no environment, no clock. The three
gate modules become shells: read the facts, call the decision, write the records. Behaviour does not change. The tests
follow the layers: table tests of the decisions (`tests/core/test_ask_decide.py`), shell tests on real files
(`tests/shell/test_ask_facts.py`, `tests/shell/test_outbox_facts.py`), and the existing one deny per refusal reason through
the real hook (`tests/test_e2e_gates.py`). Each test id is one case, each refusal reason has a deny and the nearest allow.
Not moved, as they test other things: the `mkway search` command (`tests/test_mw008_search.py`), the outbox state reader
(`tests/test_mw019_state.py`), the ask notification and board, the shell-command reader and the start line.
