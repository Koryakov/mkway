## 1. Goal

«we should have straight, simple as its possible mkway process - it should help work on tasks - not be as evil dog - it should be strong helper!» — owner, 2026-11-16 (R263). Order of the operator: fix item 1 of the wave A bundle (owner: «yes to all», 2026-11-16). The checks of the ask lane (`owner_ask.edit`, `owner_ask.stop`, `owner_ask.notify`, `outbox_check.pre`) and `search` were class `form`: a new install only watched and logged until the owner ran `gate on`, and they could trip back to watch. They become class `integrity` (R272 G1, R287a: a gate with any KIND row is integrity; R287c: per gate, search too): they refuse from the first install and never trip. Help it gives the task: an ask never reaches the owner without its sources, and a check never leaves with the wrong text, from the first day and in every install. Named limit (K8): a Stop gate cannot be wired fail-closed.
