## 1. Goal

«the tests of the family become fast and true, with the same behaviour proven» — migration task, 2026-11-12.
The decisions of the delete gate and of the trash move into `engine/core_delete.py` (small `Facts` and `Decision`
dataclasses, no I/O import); `gate_delete.py` reads the command and the facts, calls `decide` and writes the records;
`trash.py` keeps the copying, the record write and the folder removal. A fact the core does not hold is asked for with
`Need`; the shell answers it and calls again, so the same facts always give the same decision. The reader of the command
text stays in the shell (`gate_delete.read`): with a real root it asks the disk whether a `cd` target exists, which is a
fact and not a decision. Tests by layer: table tests (no disk, no git), shell tests (real files and real git, each under
20 s), and the one real-hook deny per reason that MW-039 already holds. One test id is one case; each failure-path test
says «Catches:». Not established: the mutation score of the gate.
