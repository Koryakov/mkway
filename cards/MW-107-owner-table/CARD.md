How to use: the form of `cards/_TEMPLATE/CARD.md`. The Acceptance table comes first; every row names one test node (the base id of a parametrized test) or a file read.

## 1. Goal

«we should have straight, simple as its possible mkway process - it should help work on tasks - not be as evil dog - it should be strong helper!» — owner, 2026-11-16 (yardstick R263). One owner table (`engine/owners.py`) replaces three rules (no-open-card for the lead's files, file-not-in-card for the orderer's files, the lead's writable set), so every file kind has exactly one owner who may write and commit it, and no file is left that nobody may commit (a verdict file, quote files, the lead's order files, the asks). A write outside the session's root is refused for every session unless the outside-writable list names it. Scope: this card only; no reason id removed; every refusal text only grows.
