How to use: the form of `cards/_TEMPLATE/CARD.md`. Step 2 of card 8: tests only, no engine code. Every way-out row passes at once, so it is a pin, not a red test: it names what the refusal text says as the fix and asserts the same call is allowed. A row that cannot pass without engine code is an engine gap: it is listed in the Log and stays a gap in `engine/concept.py`.

## 1. Goal

«we should have straight, simple as its possible mkway process - it should help work on tasks» — owner, 2026-11-16. Block 8 of `engine/concept.py` has 37 rows (K7 11, K3 26): each gets a way-out test, so a session that is refused can see in a test that the fix the refusal names works. Scope: tests, the way-out marks of block 8 and the two gap counters; no gate behaviour changes, no engine code.
