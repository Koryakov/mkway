## 1. Goal

«Tests before a commit, red test first, no red commit» — owner, 2026-11-10.
A `git commit` from a session runs the project's tests first, on the staged tree and never on the working tree.
A red suite refuses the commit, except the commit that holds tests only (the red-first commit); a commit of docs
only runs no tests; a run has a time budget and fails closed; one run per staged tree. The engine gets one gate
(`commit_tests`, shell group), profile keys with defaults, a reader for `paths.docs`, and one README section.
