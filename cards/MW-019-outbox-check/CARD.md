## 1. Goal

A text written from compacted memory and checked by its own author went out with a contradiction in it; the owner asked
for a cause and a guarantee, and the rule became: «every ask to the owner and every customer text is checked by a fresh
reader before it leaves». The engine makes that mechanical: a file made for someone outside the session counts as
checked only when a check file beside it holds the fixed lines, carries the sha256 of the exact text, names a checker
type that is on the profile's list, and the agent records show an agent of that type started and ended in the writing
session after the file's last change and before the check was written — order of 2026-11-11, card C.
