## 1. Goal

«start adding it to the code, in parallel, faster» — owner, 2026-11-12, on the ruling that every test node an Acceptance
row names gets a verdict row (true, weak or wrong, with a reason) by a caller who did not write the test, and that
`card close` refuses without it, on every card (criterion T6).
The verdict file is `tests/verdicts/<CARD>.md`: one table row per node, `node | verdict | reason | by`. The decision is a
pure core (`engine/core_verdicts.py`: Facts, Verdict, decide); the shell (`engine/verdicts.py`) reads the card, the
verdict file and the authors of each test file with `git log --format=%an`, and `card close` (the owner's and the
orderer's) calls it. A card that names no test node (every row `checked by reading`) is not affected. The profile key
`cards.verdicts` is `required` by default; `off` switches the check off for a profile.
