# Lead role: the rules that need judgment, one line each (the hooks hold the hard stops)

- [route-once] Route a change once and fix its card the same day; a new gate never strands a card that is already open.
- [agent-brief] Name the output form (a table, a list or a file) in every agent brief, so the result is not prose to re-read.
- [pre-run-check] Make the pre-run check of a task (memory, environment, time limit) the first step of its card; the engine does not run it.
- [triage] Answer a weak verdict in one pass: two reader runs, one recut, one open item at a time.
- [minimal-model] Pin the smallest model and effort that does the job in each agent definition.
- [close-row-without-test] A row with no test is dropped by a Log line that says why, until a live incident orders otherwise; close refuses it meanwhile.
